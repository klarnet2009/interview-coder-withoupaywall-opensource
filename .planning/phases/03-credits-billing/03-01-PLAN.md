<objective>
Add the credits data model, service layer, API endpoints, and middleware that enforce per-operation credit deductions. After this plan, every authenticated AI request checks the user's credit balance and deducts credits, and new users start with free credits.

Purpose: Enable credits-based billing so AI operations are metered and users with zero credits are blocked (CRED-01, CRED-03, CRED-04, CRED-05).
Output: CreditTransaction Prisma model, CreditService, credit balance API, credit check middleware wired into processing routes.
</objective>

         id          String   @id @default(uuid())

         balance     Float   // balance after transaction
         operation   String? // "signup_bonus", "extract", "solution", "debug", "purchase"
         description String?

         user User @relation(fields: [userId], references: [id], onDelete: Cascade)

       }

    2. Add credit cost config to `backend/src/config.ts`:
       - CREDITS_FREE_ON_SIGNUP: z.coerce.number().default(10) — per CRED-01

       Update `backend/.env.example` with the new vars.

    3. Create `backend/src/credits/credit.service.ts`:
       - CreditService class with dependency injection (prisma as constructor param for testability)
       - `getBalance(userId: string): Promise<number>` — queries User.credits, returns 0 if user not found
       - `addCredits(userId: string, amount: number, operation: string, description?: string): Promise<CreditResult>` — wraps in $transaction:
         a. Update User.credits (increment by amount)
         b. Create CreditTransaction record (amount, balance after, operation, description)
         c. Return { success: true, data: { balance, transaction } }
       - `addFreeCredits(userId: string): Promise<CreditResult>` — calls addCredits with CREDITS_FREE_ON_SIGNUP, operation "signup_bonus"
       - `deductCredits(userId: string, amount: number, operation: string): Promise<CreditResult>` — wraps in $transaction:
         a. Read current User.credits with row lock (SELECT FOR UPDATE equivalent via Prisma raw query or interactive transaction)
         b. If balance < amount, return { success: false, error: "Insufficient credits", statusCode: 402 }
         c. Decrement User.credits by amount
         d. Create CreditTransaction record (negative amount, balance after deduction)
         e. Return { success: true, data: { balance, transaction } }
       - Export singleton `creditService = new CreditService(prisma)`
       - Use discriminated union `CreditResult<T>` matching AuthResult pattern: `{ success: true; data: T } | { success: false; error: string; statusCode: number }`
