- User model: id (UUID), email (unique), passwordHash, createdAt, updatedAt

    - POST /auth/register with valid {email, password} returns 201 with { user: { id, email, createdAt }, accessToken, refreshToken }
    - POST /auth/register with duplicate email returns 409 { error: "Email already registered" }
    - POST /auth/register with missing fields returns 400 { error: validation message }
    - POST /auth/register with password < 8 chars returns 400 { error: validation message }
    - POST /auth/login with valid {email, password} returns 200 with { accessToken, refreshToken }
    - POST /auth/login with invalid email returns 401 { error: "Invalid credentials" }
    - POST /auth/login with wrong password returns 401 { error: "Invalid credentials" }
    - POST /auth/refresh with valid {refreshToken} returns 200 with { accessToken, refreshToken } (token rotation)
    - POST /auth/refresh with invalid token returns 401 { error: "Invalid refresh token" }
    - POST /auth/refresh with revoked token returns 401 { error: "Refresh token revoked" }
    - POST /auth/refresh with expired token returns 401 { error: "Refresh token expired" }
    - Password is hashed with bcrypt before storing (never stored plaintext)
    - Refresh token rotation: old token is revoked when issuing new one (per AUTH-04 security)
  </behavior>
  <action>
Create the auth module in `backend/src/auth/`. Follow the project's convention of result-pattern error handling (`{ success: boolean, data?: T, error?: string }`).

1. Create `backend/src/auth/auth.service.ts`:
   - Import bcryptjs (use bcryptjs, not bcrypt — pure JS, no native compilation issues, per project constraint of cross-platform support)
   - Import jsonwebtoken for JWT creation/verification
   - Import config from `../config` (JWT_SECRET, JWT_REFRESH_SECRET, JWT_ACCESS_EXPIRES_IN, JWT_REFRESH_EXPIRES_IN)
   - Import prisma from `../database`
   - Import uuid for token IDs

   **register function:**
   - Input: { email: string, password: string }
   - Validate: email format (use zod), password min 8 chars
   - Check if email already exists → return 409 error if so
   - Hash password with bcryptjs (salt rounds: 12)
   - Create user in database with prisma.user.create
   - Generate access token (jwt.sign with { userId: user.id }, JWT_SECRET, { expiresIn: JWT_ACCESS_EXPIRES_IN }))
   - Generate refresh token (jwt.sign with { userId: user.id, tokenId: uuid() }, JWT_REFRESH_SECRET, { expiresIn: JWT_REFRESH_EXPIRES_IN }))
   - Store refresh token in database: prisma.refreshToken.create({ data: { token: refreshToken, userId: user.id, expiresAt: <calculated from JWT_REFRESH_EXPIRES_IN> } })
   - Return { user: { id, email, createdAt }, accessToken, refreshToken }

   **login function:**
   - Input: { email: string, password: string }
   - Find user by email: prisma.user.findUnique({ where: { email } })
   - If not found, return 401 error (do not reveal whether email exists — use generic "Invalid credentials")
   - Compare password with bcryptjs.compare
   - If mismatch, return 401 "Invalid credentials"
   - Generate access token and refresh token (same as register)
   - Store refresh token in database
   - Return { accessToken, refreshToken }

   **refreshToken function:**
   - Input: { refreshToken: string }
   - Verify the JWT refresh token using jwt.verify with JWT_REFRESH_SECRET
   - If verification fails (invalid or expired), return 401 error
   - Find the token in database: prisma.refreshToken.findUnique({ where: { token } })
   - If not found, return 401 "Invalid refresh token"
   - If token.revokedAt is not null, return 401 "Refresh token revoked"
   - If token.expiresAt < now, return 401 "Refresh token expired"
   - **Token rotation (per AUTH-04 security):** Revoke the old token (set revokedAt = now)
   - Generate NEW access token and NEW refresh token
   - Store the new refresh token in database
   - Return { accessToken, refreshToken: newRefreshToken }

   **logout function:**
   - Input: { refreshToken: string }
   - Find the token in database: prisma.refreshToken.findUnique({ where: { token } })
   - If found, set revokedAt = now (prisma.refreshToken.update)
   - Return success even if token not found (idempotent logout)

2. Create `backend/src/auth/auth.routes.ts`:
   - Create an Express Router
   - POST /register → call authService.register, return 201 or error
   - POST /login → call authService.login, return 200 or error

   - POST /logout → call authService.logout, return 200 or error
   - All routes return JSON with appropriate status codes
   - Error responses follow the pattern: { error: string, details?: string }
   - Wrap each handler in try/catch that returns 500 for unexpected errors

   - Verify refresh token rotation revokes old token
   - Run tests with `cd backend && npm test -- --run`
